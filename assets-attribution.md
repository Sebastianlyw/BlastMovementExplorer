# Asset attribution

**No external assets are used.** All geometry, terrain, colours, block data and point
clouds are generated procedurally by code in this repository. No textures, HDRIs, models,
fonts or scans were downloaded.

Poly Haven CC0 rock textures were considered (licence: https://polyhaven.com/license)
but not added: the procedural, vertex-coloured terrain keeps the data readable and adds
no download weight. If an asset is added later, record here: source URL, author, licence,
download date and any modifications.

| Asset | Source | Author | Licence | Downloaded | Modified |
|---|---|---|---|---|---|
| — | — | — | — | — | — |

Third-party code is limited to npm dependencies listed in `package.json` / `package-lock.json`
(Angular, Three.js, RxJS, tslib; dev tools: Vitest, Playwright, OpenSpec, TypeScript).
